
# Ursula - Aplikasi Kasir

## Deskripsi
Ursula adalah aplikasi kasir sederhana untuk menampilkan
dan mengelola informasi barang toko.

## Teknologi
- HTML5

## Daftar Halaman
1. Daftar Barang
2. Tambah Barang
3. Detail Barang

## Fitur
- Menampilkan daftar barang dalam bentuk tabel.
- Menyediakan formulir input barang.
- Menampilkan detail barang.
- Menyediakan navigasi antarhalaman.

## Struktur Folder
- index.html
- tambah-barang.html
- detail-barang.html
- images/
- docs/screenshots/
